# bench/data/_corner2000.json 数据来源说明

> 本文件是**历史实测原始产物**，入库保留供验证脚本引用（13 处引用，含现行
> `verify_getlist_fix.py` / `verify_paper_layers.py` / `dstar_10k_serial.py`）。

## 结构

```json
{
  "layouts": [[[x, y], ...], ...],   // 2000 组雷位布局（每组为 (x,y) 坐标列表）
  "cpp":     [{"won": bool, "steps": int}, ...]  // 每组布局经纯 C++ decide
                                                  // 循环跑出的胜负与步数
}
```

## 已知损失（2026-11-10）

生成该数据的脚本 `bench/_corner2000.py` 在 2026-11-10 的历史遗留清理中被
**误删**（文件名以下划线开头，被判定规则误判为临时诊断脚本）。该文件从未进入
git 历史，**无法恢复**。

影响范围（如实评估）：
- **数据本身未丢失**：`_corner2000.json` 完整保留，13 处引用不受影响，
  相关验证脚本仍可正常读取。
- **生成过程不可复现**：无法用同一脚本重新生成完全相同的 2000 组布局。
  若需重跑，须依据本说明的数据结构重写生成器，并**明确标注为新生成、
  与原数据不可逐位比对**。

## 纪律留痕

这次误判的根因是「按文件名前缀判定临时脚本」这条规则过宽。后续清理规则已收窄：
以 `_` 开头的**数据生成器**不得按临时脚本删除，须先检查它是否被保留脚本引用
或其产物是否被引用。
