## 二、作废的判定依据（仪器校验）

对 150 点的逐点校验：

| 检查 | 读数 | 含义 |
|---|---|---|
| `PLY3` 与 `q` 的逐点相关系数 | **中位 0.9998**（均值 0.9430） | 几乎完全重合 |
| `PLY2` 与 `q` 的逐点相关系数 | 中位 0.9882（均值 0.9063） | 高度重合 |
| `min-max:PLY3` 选中格恰好是 q 最优的比例 | **110/146 = 75.3%** | 直接选了答案 |
| `PLY2 == q`（完全相等）的点 | 46/342 = 13.5% | 部分点完全等价 |

关键对照：**真值 q 本身就是"该状态完美续玩的胜率"**，
而 3-ply 在浅状态（worlds ≤ 2016、剩余候选少）上已经能穷尽绝大部分后续，
于是 `PLY3 ≈ q`。

⇒ 用 `PLY3` 当特征，等价于把评价标准泄漏进特征。
   Adviser 提醒过的"廉价估计器与真值是两个不同量"这一前提，
   **在本样本（偏简单局面）上不成立**。

## 三、这个错误是怎么发生的（如实记录）

1. 我先按 Advisor 建议改用了 2-ply/3-ply（正确方向）；
2. 但我**只做了冒烟测试**（1 个点），恰好那个点是退化点（`PLY2 == q`），
   我判断"需要更多样本确认"，然后在正式跑之前**没有完成**这个校验；
3. 正式跑出强信号后，我本可以接受它 —— 但配对检验里
   "优 11 / 劣 51" 与 "CI 全负" 的表观矛盾让我回头查，
   才发现了相关性 0.9998 这个致命事实。

**教训**：强读数出现时，第一反应应是"哪里可能泄漏/作弊"，
而不是"终于找到信号了"。本例若不是那个表观矛盾触发复查，就会以假结论收尾。

## 四、附带发现的一个真实仪器缺陷（已修）

`sign_test()` 把差值为 0 的点排除在计数外，
导致输出"优 11 / 劣 51"而 CI 全负的表观矛盾。

实际分布：
- 88 点差值 = 0（两准则选同一格，或该点 S0 已选对）
- 51 点更好
- 11 点更差

**正确表述**应是"差异点中 51 好 / 11 差，另 88 点无差异"，
而不是笼统的"优 11 / 劣 51"。此缺陷本身不改变结论，但会误导读数。

## 五、这对「开格收益作并列主准则」意味着什么

### 不能推出的
- ❌ 不能说"开格收益作并列主准则有效/无效" —— 本轮**没有**得到干净读数

### 可以确认的
1. **一步收益指标**（IG/E/U/B/R/L）在 342 点上无显著信号
   （`offline_parallel_criteria.py`：78 组合，最优 −0.003 落在 p=0.84 噪声内，
   Bonferroni 后 0 个显著）。
2. **多步估计器在现有样本上不可用** —— 因为样本 worlds ≤ 2016 太简单，
   3-ply 已经等价于真值，无法构造"独立但不精确"的估计器。

### 下一步的正确做法（若还要继续这条线）
1. **换更难的样本**：需要 worlds 显著更大的决策点（如 >2000），
   使 2/3-ply 与真值 q 产生实质差距。但这批点恰是 C++ 跑得慢的那批。
2. **限制"作弊"上限**：任何特征必须满足
   `corr(feature, q) < 阈值`（如 0.8）才允许作为候选准则，
   否则判为泄漏。这个门槛应写进脚本的硬校验。
3. **换更弱的估计器**：如 1-ply 或 rollout 少量样本，
   使其与真值有明确差距，但代价是信号更弱、需要更大样本。
