## 一、两轮实测数据

| 项 | 正式（seed 20272000+） | 独立复现（seed 20273000+） |
|---|---:|---:|
| center 胜率 | 727/2000 = **36.35%** | 723/2000 = **36.15%** |
| corner 胜率 | 792/2000 = **39.60%** | 745/2000 = **37.25%** |
| **Δ（corner − center）** | **+3.25pp** | **+1.10pp** |
| 配对 | 382 独赢 / 317 独赢 | 379 独赢 / 357 独赢 |
| McNemar p | **0.0154（显著）** | **0.4389（不显著）** |
| center 首格0率 | 15.80% | 16.50% |
| corner 首格0率 | 49.20% | 47.75% |
| 完整性 | 2000/2000 失败 0 ✔ | 2000/2000 失败 0 ✔ |

**理论参照**：Arbiter 规则下 P(首格数字=0) 角落 **49.85%**、中心 **15.45%**
（精确组合数 C(N−nb,a)/C(N,a)，N=479, a=99）。
两轮 corner 实测 49.20% / 47.75% 与该理论一致 ⇒ **机制可靠**。

## 二、按冻结判据的判定

`review/P2复现预注册.md` 规定的主判据：

> **复现的 Δ 方向必须与正式实验相同（corner > center）**

| 判据 | 结果 |
|---|---|
| **主判据：方向一致** | ✅ **满足**（两轮均为 corner > center） |
| 副判据：复现轮 p < 0.05 | ❌ 不满足（p = 0.4389） |

**⇒ 判定：方向性描述满足冻结主判据；尚未确认稳定正收益。**

## 三、准确结论（不得越界的表述）

### 可以说
1. **复现轮观察到同方向的 +1.10pp，但未显著。**
2. **角落开局的实际收益仍不确定。**
3. 两轮**方向一致**（都 corner > center），这是主判据要求的。
4. 中间指标（首格为 0 率）两轮都接近理论值 ⇒ 机制实现正确。
5. **两轮实测都不能宣称达到 40%**（正式 39.60% 的 CI [37.48, 41.76] 跨 40%；
   复现 37.25% 的 CI [35.16, 39.39] 全在 40% 以下）。

### **不能**说（Advisor 纠正的越界）
| ❌ 不能说的 | 为什么 |
|---|---|
| 「幅度未复现」 | 两轮点估计不同**不能**单独证明效应变化 |
| 「效应缩水 66%」 | 同上；3.25pp vs 1.10pp 的差异在 MDE=4.26pp 下与抽样噪声不可区分 |
| 「角落开局单独不足以达到 40%」 | 复现轮 37.25% 只是**一次**点估计，其 CI 上界 39.39% 仍接近 40%；不能据此断言"不足以" |
| 「角落开局无效」 | 方向一致 + 机制正确；只是未确认稳定正收益 |

**核心原因**：原设计的 **MDE = 4.26pp**。
在两轮都只有 2000 局的情况下，**点估计的波动幅度（3.25 vs 1.10）
落在该设计的噪声量级内** ⇒ 无法区分「效应真的变了」与「抽样噪声」。

## 四、这对 40% 目标意味着什么

| 项 | 状态 |
|---|---|
| 40% 目标 | **未达成** |
| 依据 | 两轮实测均未达到：正式 39.60%（CI 跨 40%）、复现 37.25%（CI < 40%） |
| 角落开局的贡献 | **方向可能为正，但幅度未确认**；不能作为达标依据 |

**⚠️ 注意**：这里说的是"两轮实测都不能宣称达到 40%"，
**不是**"角落开局不可能帮助达到 40%"。
后者需要更大样本或更多改进叠加才能判断。

---

## 五、若要确认稳定收益，需要什么

| 方案 | 说明 | 代价 |
|---|---|---|
| **A. 扩大样本** | 把 MDE 从 4.26pp 压到 ~2pp ⇒ 需约 8000 局/臂 | 约 2×40 分钟 |
| **B. 两轮合并** | 合并 4000 局 ⇒ MDE ≈ 3.0pp | ⚠️ 但正式轮是"先跑的、已看到结果的"，合并**含选择偏差**，只能作探索性描述 |
| **C. 与其他改进叠加** | 角落开局 + 权重优化/3-ply，联合 A/B | 需先完成 F 矩阵扩样与权重搜索 |

**当前建议**：不追加 P2 样本（边际收益低），转向 P1 权重优化线，
最后用**组合方案**做整局 A/B。
